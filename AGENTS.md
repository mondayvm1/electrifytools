# Agent notes

- Package manager: bun (`npx -y bun@1.3.5 …` if bun isn't installed).
- Do not edit `src/routeTree.gen.ts`; it is generated by the router plugin.
- Prices are server-side in `src/config/products.ts`. Never accept a price from the client.
- Secrets go in `.env.local` locally and Vercel env vars in production — never in the repo.
